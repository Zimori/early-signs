# Early Signs (An Economic Early Warning System)

How reliable are economic indicators as early warning signals of recessions across different economic regimes?

## Project Overview
Data Science project exploring whether macroeconomic indicators (unemployment rate, inflation, consumer confidence, gdp growth, interest rate variations, ...) can reliably act as early warning signals of recessions across different economic regimes.

## Why it Matters
Identifying early warning signs of economic downturns ultimately helps mitigate their impact on businesses and society as a whole. Understanding when a crisis erupts eventually allows policymakers, businesses, individuals to make informed decisions and allocate resources in a more effective way. 
> "Chance favors the prepared mind" 
> - Louis Pasteur.

## Installation
1. Clone the repository:
HTTPS:
```bash
git clone https://github.com/Zimori/early-signs.git
cd early-signs
```
SSH:
```bash
git clone git@github.com:Zimori/early-signs.git
cd early-signs
```
2. Create a virtual environment and activate it:
```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
```
3. Install the required dependencies:
```bash
pip install -r requirements.txt
```

These steps will set up project environment, allowing you to run the code and keep your machine clean.

## Research Questions
- Which economic indicators are most predictive of a recession?
- How far in advance can we predict a recession using these indicators?
- What are the limitations of using economic indicators for recession prediction?
- When do they fail? Are there specific economic regimes where they are more or less effective?
